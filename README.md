# DermaCare AI

This repository contains the Vite frontend, Express/MongoDB API, and Python image-analysis service.

- Local services, environment variables, and deployment: [backend/ai-service/README.md](backend/ai-service/README.md)
- Requirement progress and verification evidence: [docs/requirements-traceability-matrix.md](docs/requirements-traceability-matrix.md)

The image-analysis service currently returns informational image-quality and color measurements. It is not a validated medical classifier and does not diagnose skin conditions.
